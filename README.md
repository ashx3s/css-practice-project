# CSS Final Demo - Elvira Studebaker Portfolio

A web development portfolio site for Elvira Studebaker, demonstrating semantic HTML and CSS styling techniques.

## Project Overview

This project serves as a CSS demonstration for students learning web development. The site includes a home page and contact form, showcasing best practices in semantic HTML structure and CSS styling.

## Pages

- **Home Page** (`index.html`) - Features a hero section, services cards, and about section
- **Contact Page** (`contact.html`) - Contains a professional contact form with validation
- **Portfolio Page** (`portfolio.html`) - Contains almost no content. to be used for creating html and practicing styling it

## Learning Branches

This repository uses branches to support different learning stages:

- **`main`** - Clean HTML structure without styling, perfect for students to practice CSS
- **demo** - Contain completed code examples with full CSS implementation

Students are encouraged to work on the `main` branch and reference other branches to see completed solutions.

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser to view the unstyled HTML
3. Create your own CSS file and link it to practice styling
4. Compare your work with the completed branches for reference
